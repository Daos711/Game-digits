# Шарабум (Sharaboom) — Концепт-документ

## Обзор

**Жанр:** Bubble Shooter / Puzzle
**Платформа:** Web (TypeScript + Canvas/PixiJS)
**Целевая аудитория:** Казуальные игроки, мобильные и десктоп

---

## Основная механика

### Игровое поле
- Прямоугольная область с шарами, свисающими сверху
- Шары укладываются в **гексагональную сетку** (каждый чётный ряд смещён на половину диаметра шара)
- Внизу экрана — **пушка** с текущим шаром для выстрела
- Стены слева и справа — шар **отскакивает** от них

### Управление
- **Мышь/тач:** Прицеливание — линия показывает траекторию (включая отскок от стены)
- **Клик/тап:** Выстрел шара в направлении прицела
- Шар летит по прямой, отскакивает от стен, прилипает к первому шару/потолку на пути

### Правила соединения
- Выпущенный шар **прилипает** к ближайшему шару того же цвета или к потолку
- Если образуется группа из **3+ шаров одного цвета** — все они **уничтожаются**
- Все шары, которые после уничтожения **больше не соединены с потолком**, **падают** (дают бонусные очки)

---

## Условия игры

### Проигрыш
- Шары достигают **нижней границы** (линия смерти)
- Новые ряды спускаются сверху постепенно:
  - Каждые **N выстрелов** (например, 5-7) сверху добавляется новый ряд
  - Или по таймеру (каждые 10-15 секунд)

### Победа (опционально)
- **Бесконечный режим:** Играть пока не проиграешь, цель — набрать максимум очков
- **Уровневый режим:** Очистить поле полностью за ограниченное число выстрелов

## Система очков

### Базовые очки
| Действие | Очки |
|----------|------|
| Уничтожение 3 шаров | 30 |
| Уничтожение 4 шаров | 50 |
| Уничтожение 5 шаров | 80 |
| Уничтожение 6+ шаров | 80 + 20 за каждый дополнительный |

### Бонусные очки
| Действие | Очки |
|----------|------|
| Падающий шар (отвалился) | 20 за каждый |
| Комбо (несколько групп за выстрел) | x1.5 множитель |
| Рикошет от стены перед попаданием | +10 бонус |
| Двойной рикошет | +30 бонус |

### Множители сложности
- Чем дольше играешь, тем больше множитель очков (x1.0 → x1.5 → x2.0)
- Стимулирует продолжать игру

## Цвета шаров

Базовый набор (4-6 цветов, увеличивается со сложностью):

| Уровень сложности | Цвета |
|-------------------|-------|
| Начало | Красный, Синий, Жёлтый, Зелёный |
| Средний | + Фиолетовый |
| Сложный | + Оранжевый |

Цвет следующего шара выбирается **только из цветов, присутствующих на поле** (чтобы не было безвыходных ситуаций).

---

## Бонусные шары (Power-ups)

Появляются после уничтожения определённого количества шаров или случайно.

| Бонус | Иконка | Эффект |
|-------|--------|--------|
| **Бомба** | Чёрный шар с фитилём | Уничтожает все шары в радиусе 2 клеток |
| **Лазер** | Белый светящийся | Прорезает насквозь, уничтожает все шары на пути |
| **Радуга** | Переливающийся | Джокер — соединяется с любым цветом |
| **Молния** | Жёлтый с искрами | Уничтожает все шары одного случайного цвета |
| **Заморозка** | Голубой со снежинками | Останавливает спуск шаров на 15 секунд |

### Получение бонусов
- Каждые **50 уничтоженных шаров** — случайный бонус
- Или: индикатор заполняется, при заполнении — выбор бонуса

## Визуальные эффекты

### Анимации
- **Выстрел:** Шар вылетает с лёгким trail-эффектом
- **Попадание:** Небольшая вспышка при прилипании
- **Уничтожение:** Шары лопаются с частицами (pop effect)
- **Падение:** Отвалившиеся шары падают вниз с bounce-эффектом
- **Рикошет:** Искры при отскоке от стены
- **Спуск новых шаров:** Плавная анимация сверху вниз

### Соки (Game Feel)
- Screen shake при большом комбо
- Замедление времени (slow-mo) при критическом уничтожении
- Звуковые эффекты: pop, bounce, combo, danger

#### 2. Поиск связанных шаров (Flood Fill)
```typescript
function findConnectedBalls(startBall: Ball, grid: Grid): Ball[] {
  const visited = new Set<Ball>();
  const queue = [startBall];
  const color = startBall.color;

  while (queue.length > 0) {
    const ball = queue.shift()!;
    if (visited.has(ball)) continue;
    if (ball.color !== color) continue;

    visited.add(ball);
    for (const neighbor of getNeighbors(ball, grid)) {
      queue.push(neighbor);
    }
  }
  return Array.from(visited);
}
```

```typescript
function findFloatingBalls(grid: Grid): Ball[] {
  // BFS от потолка — все достижимые шары "держатся"
  const attached = new Set<Ball>();
  const topRow = grid.getRow(0);

  // BFS от каждого шара в верхнем ряду
  for (const ball of topRow) {
    // ... помечаем все достижимые как attached
  }

  // Все шары не в attached — падают
  return grid.allBalls().filter(b => !attached.has(b));
}
```

#### 4. Траектория с отскоком
```typescript
function calculateTrajectory(
  start: Point,
  angle: number,
  walls: {left: number, right: number}
): Point[] {
  const points: Point[] = [start];
  let x = start.x;
  let y = start.y;
  let dx = Math.cos(angle);
  let dy = Math.sin(angle);

  while (y > 0) {
    x += dx;
    y += dy;

    // Отскок от стен
    if (x < walls.left || x > walls.right) {
      dx = -dx;
      points.push({x, y}); // Точка отскока
    }
  }
  return points;
}
```
